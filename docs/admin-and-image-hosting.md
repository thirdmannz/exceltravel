# 後台維護與圖片託管

## 登入

直接使用 https://exceltravel.netlify.app/admin/ ，不需要 `?v=9` 等測試參數。
使用 email、密碼及 Authenticator 六位驗證碼。Google 登入目前尚未設定，不能作為忘記 2FA 的救援方式。

## 新增帳號與權限

1. 使用管理員帳號登入，開啟「帳號與權限」。
2. 按「新增帳號」，輸入 email 與至少 12 字元的初始密碼。
3. 選角色預設，再勾選實際需要的權限。admin 擁有全部權限，不受勾選限制；一般員工請用 editor 或 media。
4. 建立後會開啟新帳號的 2FA QR。請讓該員工用自己的 Authenticator 掃描，不要將 QR 發到群組。
5. 現有帳號可按「編輯」調整角色與權限，亦可停用或重設 2FA。
6. 忘記密碼時，按該帳號的「重設密碼」，在遮罩欄位輸入新密碼（12 至 1024 字元）。舊密碼立即不能用於新登入；既有登入工作階段不會自動登出。
7. 按「關閉 2FA」可改為只用密碼登入（會先要求確認）。按「開啟 2FA」或「重置 2FA」會產生全新 QR，需要重新掃描；舊密鑰不再有效。停用 2FA 會降低帳號安全性。

登入頁的 2FA 欄位可留空，但只有管理員已關閉該帳號 2FA 時才會成功。新增帳號預設啟用 2FA。

## 圖片已由本站託管

`/assets/images/wix/` 是本站的檔案路徑，不是 Wix 網域。保留名稱可避免破壞現有引用。
本地有 91 個圖片檔案（含響應式版本與舊原檔），build 只發布仍被引用的資源。
目前公開行程資料沒有 Wix CDN URL；16 個不同的行程圖片路徑均已在 Netlify 上確認 200 且內容雜湊與本地一致。

上述範圍是目前這個網站正在使用的圖片，不代表已備份 Wix Media Manager 中從未用在本站的檔案。取消 Wix 前，如需那些未使用照片，仍須從 Wix 媒體庫匯出。

## 自行換圖

在「行程管理」打開現有行程，按圖片的「上傳」，選 PNG/JPEG/WebP（每張上限 5MB），再儲存行程。
圖片存進 Netlify Blobs，公開路徑為 `/data/uploads/<name>`，不是 Wix。
不需要 git push 或重新部署；上傳、API 存取仍計入 Netlify 用量。

注意：目前「行程管理」只支援編輯現有行程，沒有新增完整行程的 POST API。特價專區有新增草稿功能，但不是新增完整旅遊行程。完整新行程建立與發布功能尚未完成，不能用此文件宣稱已支援。
